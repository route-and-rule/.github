## 👩‍💻 About this lab

Hands-on network engineering projects built from scratch: configuring, securing,
breaking and auditing real network setups, and writing tools that catch the
mistakes engineers make in production.

## 🛠️ Projects

| Project | What it does | Tech |
|---|---|---|
| [**fwaudit**](../../fwaudit) | Firewall policy analyzer: finds shadowed, duplicate and risky rules in **Linux iptables** and **Cisco ASA** configs | Python · iptables · Cisco ACL |
| *coming soon* | More network engineering projects on the way | |

## 📚 Skills in these projects

- **Firewalls & security:** iptables, Cisco ASA ACLs, stateful filtering, least privilege, rule-order analysis
- **Networking:** TCP/IP, subnetting, ports & services, interfaces & zones (LAN / DMZ / WAN)
- **Automation:** Python tooling, CLI tools, parsing device configs

## 🎯 Learning path

`CCNA concepts` → `Firewall design` → `Config auditing` → `Network automation`
