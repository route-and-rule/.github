## 🌐 Why networking?

Every app, every website and every message depends on a network working quietly
in the background, and on someone making sure it's **fast, reliable and secure**.

I'm drawn to network engineering because it sits right where **design meets security**:
- 🧱 **Building** networks that are well-structured and easy to manage
- 🛡️ **Protecting** them with firewalls, segmentation and least-privilege access
- 🔍 **Investigating** problems by following the traffic and finding the root cause
- ⚙️ **Automating** repetitive tasks so networks stay consistent and error-free
